DesktopPet 0.1.0
================

DesktopPet 是一款可互动的少女桌面宠物。本版本包含桌面行走、睡觉、
养成互动、小狗伙伴、羽毛球小游戏、AI 聊天与主动陪伴、QQ音乐/网易云音乐
本地播放状态检测等功能。

基本操作
--------
- 左键点击桌宠：互动。
- 左键拖动桌宠：移动她的位置。
- 右键点击桌宠：打开功能菜单。
- AI 聊天需要用户在聊天设置中填写自己的 API 地址、模型名称和 API Key。
- 音乐中心读取 Windows 向系统公开的媒体状态，不读取播放器账号、Cookie 或歌单。
- 屏幕感知 1.0 只读取前台和可见应用的进程名称，不读取窗口文字、文件或屏幕画面。

数据与隐私
----------
聊天设置、聊天记录、养成存档和陪伴记忆仅保存在当前 Windows 用户的
Godot 应用数据目录中。安装包不包含开发者 API Key、聊天记录或个人存档。

卸载
----
可在 Windows“设置 -> 应用”中卸载 DesktopPet。卸载不会自动删除用户存档。
